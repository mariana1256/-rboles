Clasificación Inteligente de Especies Iris

Implementación avanzada del algoritmo ID3 basada en Entropía de Información.

Metodología CRISP-ML

1. Comprensión

Definición de objetivos de negocio y traducción a una tarea de clasificación supervisada.

2. Datos

Extracción de 150 muestras del dataset Iris (UCI Machine Learning Repository).

3. Modelado

Uso de Árboles de Decisión para generar reglas de clasificación altamente interpretables.

Arquitectura del Modelo

El algoritmo ID3 utiliza la Ganancia de Información para seleccionar las características que mejor dividen los datos.

Desempeño y Métricas

96.6% Exactitud Global
100% Recall Setosa
